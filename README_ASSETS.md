# README_ASSETS — Инструкция по ассетам

Все ассеты кладутся в папку `assets/` в корне проекта.  
Движок загружает их через `ResourceLoader.exists()` → `load()`. Если файл не найден — автоматически используется процедурная геометрия.

---

## Структура папок

```
assets/
├── models/          ← 3D-модели (GLB)
├── sprites/
│   ├── buildings/   ← PNG-спрайты зданий (billboard)
│   ├── units/       ← PNG-спрайты или спрайт-шиты юнитов
│   └── resources/   ← PNG-спрайты ресурсных узлов
└── icons/           ← (зарезервировано) иконки для HUD-кнопок
```

## 3D-модели (`assets/models/`)

| Имя файла        | Юнит / Здание   | Масштаб в коде |
|------------------|-----------------|----------------|
| `castle.glb`     | Замок           | 1.0×           |
| `barracks.glb`   | Бараки          | 1.0×           |
| `mine.glb`       | Рудник          | 1.0×           |
| `smithy.glb`     | Кузница         | 1.0×           |
| `worker.glb`     | Рабочий         | 0.85×          |
| `spearman.glb`   | Копейщик        | 0.85×          |
| `archer.glb`     | Лучник          | 0.75×          |

**Требования:**
- Формат: GLB (не GLTF, один бинарный файл)
- Ось Y — вверх; корень модели стоит на `y = 0`
- Полигонов: до ~5 000 на модель (прототип)
- Анимации (Idle, Walk, Attack, Death) — приветствуются, но не обязательны

### Спрайт-шиты (SpriteSheetParser — продвинутый вариант)

Система `SpriteSheetParser` автоматически подбирает файлы по суффиксу имени.

**Правила именования:**

```
<ИмяЮнита>_Idle-Sheet.png
<ИмяЮнита>_Walk-Sheet.png     (или _Run-Sheet.png)
<ИмяЮнита>_Attack-Sheet.png   (или _Attack1-Sheet.png)
<ИмяЮнита>_Death-Sheet.png
<ИмяЮнита>_Hurt-Sheet.png
```

**Пример:** `Lancer_Idle-Sheet.png`, `Lancer_Attack-Sheet.png`

**Формат файла:**
- Горизонтальная полоска квадратных кадров: ширина = высота × количество_кадров
- Пример: 8 кадров по 128×128 = итоговый файл 1024×128
- PNG, RGBA, без полей между кадрами

## Фракционные ассеты (будущее)

`SpriteSheetParser.build_animated_sprite(folder_path)` принимает путь к папке.  
Для каждой фракции предполагается своя папка:

```
assets/sprites/factions/
├── humans/
│   ├── Warrior_Idle-Sheet.png
│   └── ...
├── undead/
├── orc/
├── elves/
└── dwarves/
```

> Вызов: `SpriteSheetParser.build_animated_sprite("res://assets/sprites/factions/humans")`
