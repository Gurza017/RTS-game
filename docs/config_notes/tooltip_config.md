# Заметки к scripts/tooltip_config.gd (сняты 27.10.2026)

Конфиг всплывающих карточек юнитов (hover modal / tooltip): что показывает
карточка и в каком порядке — задаётся здесь, а не в коде HUD. Файл намеренно
без `class_name` (не зависит от кэша глобальных классов — тот же приём, что у
`unit_stats_config.gd` и `forge_config.gd`).

## Главное правило и откуда файл
«Нет параметра в `visible_stats` — нет строки в окне». Список у объекта —
исчерпывающий перечень того, что рисуется: убрать «Броню» у рабочего =
удалить строку из списка, добавить «Дальность» монаху = дописать. Кода не
касаемся: `HUD._unit_card` идёт по списку сверху вниз. Файл появился потому,
что раньше состав карточки был зашит в код последовательностью `append`,
часть строк добавлялась безусловно, и у рабочего в тултипе стояло «Armor 0» —
параметра, которого у него по смыслу нет.

## Порядок блоков карточки (HUD._show_card)
1) иконка + название (`icon` / `display_name`); 2) строки параметров
(`visible_stats`, порядок = порядок списка); 3) описание — `role` / `skills`
/ `special` (ТЗ 20.10.2026, блок 3: «Тип / Умения / Особое умение» тремя
строками вместо абзаца; `description` остался запасным текстом для объектов
без этих полей); 4) цена (`show_cost`, сама цена приходит от вызывающего).

## value_type и источники (схема PARAMS)
- `"stat"` — «База + Кузница + Опыт = Итог» цветной формулой; только для
  того, на что бонусы действуют (атака, броня, HP…).
- `"current_max"` — «Здоровье: 80/100»; требует живого юнита, в карточке
  найма живого нет и строка показывает один максимум.
- `"plain"` — одно число по формату `fmt`; `"pair"` — два числа конфига в одну
  строку по `fmt`.
- Источник из `unit_stats_config.STATS`: `"stat"` — один ключ, `"sum_of"` —
  сумма (защита = defense + armor), `"max_of"` — максимум (атака = max из
  attack_1/attack_2), `"stats"` — ключи для `"pair"`.
- `"bonus"` / `"upgrade"` — ключи прибавок кузницы и старых плоских
  апгрейдов; `"digits"` — знаков после запятой (у скорости 1, у остального 0).

## Копейщик и мечник — без «Дальности» и «Удар раз в N с»
Заказ владельца; у мечника — ТЗ 29.09.2026, блок 4. Обе строки — техническая
отладка, а не сведения для игрока: у копейщика «дальность» — длина копья
(2 м), число ничего не сообщает, а рядом со строкой лучника (20 м) ещё и
путает; темп удара игрок оценивает глазом, а сравнивать его между родами
войск по секундам нельзя — урон за удар разный. Записи `range`, `cooldown`,
`morale`, `arrow`, `hp_current` в `PARAMS` остались библиотечными — ни одна
карточка их сейчас не собирает.

## Монах — иконка и броня
Готового портрета у монаха нет — берётся первый кадр его боевого листа
(`Blue Units/Monk/Idle.png`), тот же путь и приём, что у кнопки найма в
Замке (`HUD.UNIT_ICONS` + `FRAME_SHEET_ICONS` обрезают кадр по силуэту).
Брони у монаха нет по конфигу — строки «armor» в его списке тоже нет.

## DEFAULT_VISIBLE_STATS
Набор для `unit_id`, которого в `TOOLTIPS` ещё нет: новый юнит получает
осмысленную карточку сразу. «armor» не входит намеренно — параметр, который
чаще всего нулевой; по умолчанию лучше промолчать, чем показать ноль.

## base_value / pair_values — второй рубеж
`base_value` возвращает `[value, found]`; `found = false` — в `STATS` юнита
такого ключа нет, строка не рисуется, даже если параметр перечислен в
`visible_stats`. `pair_values` требует все ключи пары: половинчатая строка
хуже отсутствующей. `param()` накладывает запись из `visible_stats` поверх
библиотечной — так в карточке можно переопределить подпись («Здоровье» →
«Живучесть»), не трогая `PARAMS`; пустой словарь — опечатка в ключе, строка
молча не рисуется.
