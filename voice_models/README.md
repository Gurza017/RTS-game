# Модели распознавания речи

Сюда кладётся распакованная модель Vosk для русского языка:

    https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip

После распаковки должна существовать папка
`voice_models/vosk-model-small-ru-0.22/` (внутри `am/`, `graph/`, `conf/`, …).

Файл `.gdignore` в этой папке обязателен: без него Godot попытается
импортировать тысячи файлов модели. Сама модель в git не входит (45 МБ),
в экспорте её надо положить в `voice_models/` рядом с исполняемым файлом.
Ищет её `VoiceControl.model_path()`.
