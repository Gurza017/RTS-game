# Ten Thousand Spearmen

Прототип 3D RTS на Godot 4.6 (рендерер GL Compatibility) в духе Total War /
Cossacks: экономика, постройки, добыча ресурсов и бои «стенка на стенку».

Мир строится кодом во время выполнения: рукописных сцен всего две —
`scenes/MainMenu.tscn` (меню) и `scenes/Main.tscn` (пустой корень с `Main.gd`).
Бойцы рисуются billboard-спрайтами из лент кадров, здания — процедурными
мешами, замок берётся из `assets/models/castle.glb`.

**Настройки баланса — в `BALANCE.md`.** Там расписано, какое число где лежит.
**Куда класть ассеты — в `ASSETS.md`.**
**Устройство кода, замеры и ловушки — в `CLAUDE.md`.**

## Как открыть

1. Godot 4.6, ветка **Standard** (не .NET): https://godotengine.org/download
2. Import → `project.godot`.
3. F5 → главное меню → «СТАРТ ИГРЫ».

## Управление

- **WASD / стрелки**, **край экрана** — камера; **колесо** — зум; **СКМ** — панорама
- **ЛКМ** — выделить (клик или рамка); **Shift** — добавить к выделению
- **ЛКМ по чужому бойцу** — карточка разведки: состав, характеристики, ранг
- **Ctrl+1..9 / 1..9** — сохранить/вызвать группу (двойное нажатие — камера к ней)
- **ПКМ** — приказ: по земле — марш строем, по врагу — атака, по ресурсу
  (рабочими) — добыча; **двойной ПКМ** — бег
- **ПКМ с протяжкой** — построить шеренгу вдоль линии
- **ПКМ по руинам с выделенными рабочими** — отстроить здание заново
- **Alt** — показать/скрыть все полоски здоровья
- **Z / Пробел** — тактическая пауза: мир стоит, интерфейс работает
- **F11 / Alt+Enter** — полный экран; **ESC** — закрыть панель, затем меню паузы

## Игровой цикл

1. Первый замок **бесплатный** и ставится внутри зелёной площадки в своём углу.
   Вместе с ним появляются четыре рабочих: сначала они достраивают замок, потом
   расходятся по ресурсам.
2. Замок нанимает рабочих и мечников, принимает добычу, капает золотом, лечит
   и пополняет отряды в гарнизоне.
3. Из замка строятся бараки (копейщики, лучники), кузница (древо исследований),
   рудник, дома.
4. Ресурсы: дерево, золото, камень, еда, вода. Руда и камень стоят **кластерами**
   с общим запасом: рабочие занимают места по внешнему обводу кучи.
5. Кузница ведёт древо 5×4 на каждый род войск. Колонка D — способности, их
   докупает каждый отряд отдельно (например, «Залповый огонь» лучников).
6. Отряды копят опыт и получают ранги: над строем висит звезда, награда
   выбирается игроком из пяти вариантов.
7. Враг первые пять минут развивается и патрулирует, затем воюет: исследует
   кузницу, обходит с фланга мечниками, отводит лучников за пехоту и уводит
   разбитые отряды в замок.
8. Победа — снести всё чужое; поражение — потерять всё своё.

## Что уже сделано из «дороги к масштабу»

Задачи из первой редакции этого файла закрыты и замерены (таблицы — в `CLAUDE.md`):

- боец больше **не физическое тело** и не имеет своего покадрового тика:
  `Unit extends Node3D`, весь обход армии идёт одним циклом в `GameManager`;
- вся армия рисуется **общими MultiMesh** (`FarUnitRenderer`), метки выделения,
  полоски здоровья и растительность — тоже;
- соседи ищутся по **плоской сетке над колонками данных** (`ArmySoA`), разбор
  наложения — один пакетный проход;
- обход армии **дробится по кадрам** (до трёх шардов), картинка между шагами
  сглаживается.

Замеры: 5000 бойцов укладываются в бюджет физкадра (14.8 мс из 16.6);
15000 маршируют за 48.6 мс. Потолок дальше — сам интерпретатор GDScript.

## Известные ограничения

- **Нет поиска пути**: движение прямолинейное, обход — скольжение вдоль
  препятствия. Маски столкновений отключены намеренно.
- **Свои не расталкивают друг друга** и свободно проходят насквозь: любая
  попытка «умной» толкотни кончалась дрожащей и застревающей толпой.
- Нет мультиплеера и сохранений.
- Выбор фракции в меню переключает только папку спрайтов; содержимое есть
  только у `humans`.
