# Ten Thousand Spearmen

Прототип 3D RTS на Godot 4.6 (рендерер GL Compatibility), в духе Total War / Cossacks: экономика, постройки, добыча ресурсов и бои юнитов «стенка на стенку».

Мир строится кодом во время выполнения: единственные сцены — `scenes/MainMenu.tscn` (главное меню) и `scenes/Main.tscn` (пустой корень с `Main.gd`). Юниты рендерятся billboard-спрайтами из `assets/` (PNG-спрайтшиты), здания — процедурными мешами; замок использует GLB-модель.

## Как открыть проект

1. Установите Godot 4.6 (стабильная версия, ветка Standard, не .NET): https://godotengine.org/download
2. Откройте Godot, нажмите "Import", выберите файл `project.godot` из этой папки.
3. Нажмите F5 (или Play) — откроется главное меню, из него кнопка «СТАРТ ИГРЫ».

## Управление

- **WASD / стрелки** — движение камеры
- **Наведение мыши на край экрана** — панорамирование
- **Колесо мыши** — зум; **СКМ (зажать + двигать)** — вращение камеры
- **ЛКМ (клик)** — выбрать юнит/здание; **ЛКМ (рамка)** — выбрать несколько
- **Shift + клик/рамка** — добавить к выделению
- **Ctrl+1..9 / 1..9** — сохранить/вызвать группу (двойное нажатие — центрировать камеру)
- **ПКМ** — приказ: по земле — движение строем, по врагу — атака, по ресурсу (рабочим) — сбор
- **ПКМ (провести линию)** — построить войска в шеренгу вдоль линии
- **ESC** — пауза / отмена размещения здания

## Игровой цикл

1. В начале партии постройте Замок (кнопка в HUD, 300 дерева + 200 золота) — кликните по месту на карте. Вместе с замком появляются 5 рабочих, которые сами идут добывать ресурсы.
2. Замок тренирует рабочих и мечников, пассивно приносит золото и принимает ресурсы.
3. Стройте из замка: Бараки (копейщики ×20, лучники ×10), Кузницу (апгрейды урона/защиты/здоровья — раздельные для каждой фракции), Рудник (пассивное золото).
4. Ресурсы: дерево, золото, камень, еда, вода. Добываются рабочими из деревьев, месторождений и колодцев.
5. Враг (красный, правый верхний угол) первые 5 минут мирно развивается и патрулирует, затем тренирует армию и атакует. Каждые 35 секунд после активации приходят волны подкреплений (максимум 3).
6. Победа — уничтожить все здания и юниты врага; поражение — потерять всё своё после постройки замка.

## Известные ограничения

- **Нет обхода препятствий и pathfinding** — юниты движутся по прямой (collision_mask отключён намеренно, чтобы избежать дрожания).
- **ИИ простой**: конечный автомат на таймерах, без разведки и адаптации.
- **Нет тумана войны, нет мультиплеера, нет сохранений.**
- Выбор фракции в меню влияет только на набор спрайтов (папки `assets/factions/`), содержимое есть только у `humans`.

## Дорога к масштабу «10 000 юнитов»

Текущая архитектура (CharacterBody3D на юнит + перебор групп для поиска целей) комфортна для десятков-сотен юнитов. Для тысяч нужно:

1. `MultiMeshInstance3D` (GPU-инстансинг) вместо отдельных узлов на юнит.
2. Flow-field / boid-движение формаций вместо per-unit steering.
3. Пространственное разбиение (spatial hash / grid) для поиска целей вместо обхода всех юнитов каждый тик.
4. Разделение симуляции и рендера, обновление логики батчами.
